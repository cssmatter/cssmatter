</p>About me
I’m a Pune-based engineer with 15+ years of experience building web applications and design systems. My core strength is front-end engineering: taking a product from design through implementation, making shared UI patterns practical, and working closely with product, design, and API teams to ship dependable features. 


I’ve worked across enterprise commerce, licensing, analytics, and collaboration products, including programs for Cisco. Along the way, I’ve led technical discussions, estimated work, supported releases, and helped teams solve production issues. 

These days, I also build independent digital products and learning tools—from certification practice experiences to mobile apps and technical learning content.
What I work on
- Frontend architecture: Angular, React, TypeScript, JavaScript, RxJS, HTML, SCSS
- Design-to-code: Responsive interfaces, reusable components, accessibility-minded UI, Figma handoff
- Data-rich products: REST API integration, dashboards, charts, tables, and complex workflows
- Full-stack collaboration: C#, ASP.NET Core, Entity Framework Core, SQL Server, Supabase
- Product delivery: Technical leadership, estimation, Agile delivery, cross-team coordination, and production support
